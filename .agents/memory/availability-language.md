Use this language henceforth:

- “1–2 Spots Left: 1 Spot Remaining — Book Soon (Creates immediate urgency for remaining dates)”
- “At Capacity: Sold Out or Class Full”
- “VA Registration Deadline Passed: Enrollment Closed for VA Applicants (Use only if distinct from capacity)”

Do not use “Enrollment Closed” as a generic capacity label. A VA-only deadline must not imply that the class is full or that other applicants cannot register.

**Why:** The user explicitly requested these terms to distinguish capacity from a VA registration deadline, and confirmed that the limited-seat urgency wording helped sell school spots.

**How to apply:** Apply the wording when creating or editing school availability labels. Keep sold-out labels and booking availability consistent, and never invent a VA cutoff or remaining-seat count.

## VA approval prerequisite

The user is awaiting VA accreditation approval. Wait until the user confirms approval before implementing sheet-driven availability updates. Make those changes at the same time as the VA-specific registration changes, which will require very specific information for VA applicants.

The deferred availability approach is to let the user maintain remaining-seat counts and sold-out status in the existing School Dates sheet, with both sites displaying the appropriate wording and booking availability automatically. Automatic seat deductions from reservation submissions are not part of this approach.

**Why:** The user asked to coordinate these changes after approval rather than implement availability automation now.

**How to apply:** When the user confirms VA approval, revisit the availability and registration work together and obtain the exact VA registration requirements before implementation. Do not assume approval or invent required VA fields.
