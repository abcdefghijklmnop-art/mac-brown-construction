# Fly Fishing Guide School — Replit Drop-In Files

## What's here

Three files that match the Mac Brown Fly Fish Replit project structure exactly:

```
src/
  App.tsx                  ← Router (replaces your existing App.tsx)
  components/
    layout.tsx             ← Nav + Footer (replaces your existing layout)
  pages/
    home.tsx               ← Homepage (new file)
```

## How to drop into Replit

1. Open your Replit project
2. Replace `src/App.tsx` with the contents of `App.tsx`
3. Replace `src/components/layout.tsx` with the contents of `components/layout.tsx`
4. Create `src/pages/home.tsx` and paste the contents of `pages/home.tsx`
5. Hit Run — the homepage will render immediately
